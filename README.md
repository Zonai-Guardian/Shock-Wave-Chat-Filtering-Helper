# Shock-Wave-Data-Helper
This repository and website were made so that I could have chat filtering (To exclude swear words and cursing) in **Shock Wave**. However, to exclude those words, the code needs to know what they are. I could have just included the words in the source code but I'd rather keep the **Shock Wave Project** free from things like that, even in the source code.
That's why I made this repository and website, and I didn't make the words visible on the website but it is in the code.
